## 天堂：把噪点换成星空银河

### 原来的毛病

旧版天空是 7 档色阶 + 4×4 Bayer 抖动（`bayer(x,y)` 逐像素决定用哪个档）。这块抖动在平滑天空上就是"噪点"，用户第一眼指出来是对的。抖动只适合色阶过渡很小、需要避免硬边的地方；大面积天空应该直接**平色带**。

### 现在的做法

1. 天空 = 7 条平色带，边界按 `f*f*6.2` 曲线分档，**零抖动零噪声**。
2. 银河：`spineX(x) = -132 + 0.12x + 11sin(0.013x) + 4sin(0.045x+1.2)`，一条带起伏的斜轴。
   - 三层光：veil（d<96，α0.09）、arm（d<44+10nz，α0.22）、core（d<15+9nz，按 nz 起伏 ×0.8）。
   - 暗尘带 **两条**：`off = 13 + 9sin(0.021x+0.7) + 5sin(0.068x+2)`，一条在 +off、一条在 -0.8off，
     宽度 3.0–3.6 px —— 这是让银河"像星系而不是像一团雾"的关键。
   - 颗粒化：`hash(x,y) > 0.72` 的单像素提亮 0.1–0.32，让光有颗粒感而不是平滑渐变。
3. 星表（模块加载时一次算定，**不逐帧随机**，否则会像静电）：
   - 1500 颗沿 spine 分布：2/3 在 ±26px 内，其余 ±55px；另 340 颗全场稀疏。
   - 星等 `starMag(near,r) = 0.18 + 0.55·near + 0.35·r`，越贴 spine 越亮。
   - 每颗独立闪烁频率/相位，5% 带十字闪光（4 px + glow）。
4. 新月在 (96,-137) r7：第二个圆盘挖掉左半，留蛾眉 + 柔和 halo，亮度缓慢呼吸。
5. 云海重打光：远两排吃地平线余光（lit 0.34 / 0.18 / 0.07），近三排转冷（tone 2），
   lobe 更大更少（rx 24→44、n 9），行数不变，避免"一堆硬币"。
6. 流星：每个 16 s 循环一趟，9 px 拖尾，只在 0.06–0.115 的时间窗出现。

### 性能：静态天空要缓存

初版重做后 26–29 ms/帧（旧版 14.3 ms），因为天空每个像素都在查一次多倍频噪声。天空其实是静态的，
只有星星闪、云在飘。改成首帧烘焙进缓存、之后逐行拷贝：

- `SKYC`/`SKYL`（颜色/发光色）用 **Float64Array** —— 32 位颜色把 alpha 放在 bit 24–31，`Float32Array`
  的 24 位尾数会把它整个舍掉，缓存出来整条银河变成青色（这个坑真踩了），`SKYK`（光强）用 Float32 即可。
- 缓存键是调色板 `NL.join()`，换配色自动重烘。
- 结果 16.6–17.2 ms/帧。

## 回退保护（下线场景不能把用户配置挂住）

`params.js` 的 `normalize()` 加：

```js
const known = (id) => EFFECT_IDS.includes(id) || isExt(id);
if (!known(c.fx)) c.fx = d.fx;
c.rules = c.rules.filter((r) => known(r.fx));
c.cycle.list = c.cycle.list.filter(known);
```

实测：`{fx:"palette/hell", cycle.list:["palette/hell","palette/heaven"], rules:[08:00 hell]}`
→ `fx: weather/snow`、`cycle: ["palette/heaven"]`、`rules: []`。
